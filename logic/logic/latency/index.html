Gemma 4 31B

At 93.3% accuracy; the best is 94.0%. Cost basis: our GPU time while the run was running, first to last answer × $2.49/h. Among all 35 setups.

SubQ Snap Preview and SubQ Snap 1.1 returned the same answer to every question (and the same probabilities on 1,125 of 1,125); shown once.

Latency is the wall time of each request from our machine; runs that shared a GPU or ran with several requests in flight slow each other down, so throughput (questions / min) depends on the run's concurrency. In flight: requests in flight on average, the sum of request latencies over the run's active time (its first to last answer with gaps of more than 10 minutes left out), e.g. “≈ 6” is six at a time.

Median latency is per request; with several requests in flight a run finishes faster than requests × median.
