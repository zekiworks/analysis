Data

Everything the pages show comes from these files. They hold aggregate numbers and every answer, but not the questions: the publisher owns them.

FileContentsSize
results.jsonEvery published number: each setup's accuracy, confidence, latency and cost, and the routing replays and live tests.4.3 MB
answers.jsonEvery answer of every run, with its score and option probabilities, and the prompts. No question text.58.9 MB
picks.jsonBuilt from answers.json for these pages: each leaderboard setup's pick and score on each scored question.1.2 MB

Results changelog

What changed in each results version that went live (results_version in results.json), newest first. It starts with results 0eb1e828, the release that added Liquid d1-2B; earlier versions are in the repository's history.

Results 2c430f54 (1 November 2026)

  • Added SubQ Snap 1.1 (subq-snap-1.1, public preview) through SubQ's Decisions API. Text: five runs over the 2,198 scored questions (runs 346, 387, 388, 389 and 390), 63.9% right, 12th of 37 decision models, the five runs identical. Page images: condition A from run 346 (58.1%), B (45.7%), C (62.9%) and D with each of the four OCR models (49.7% to 54.3%), over the 763 page-image questions (runs 62 to 67). Its probabilities arrive as 32-bit floats. As an experimental rule of ours for this model only, the check before its runs accepted sums within 32-bit rounding. Run 346 was paused twice while that rule's approval was confirmed; its note gives the effect on its request times. The SubQ Snap Preview rows are unchanged.
  • "I don't know option" tab: SubQ Snap 1.1 added (run 392).
  • From the new row: the summary's "Better than a flat guess" line now names SubQ Snap 1.1 with Perplexity Decider 27B v1.1 (31.5% each) after Open-Jev 27B v1.1. SubQ Snap Preview's places on the Routing tab move down one in front of Opus 5.5 low (seventeenth) and Astra low (fifteenth). One neighbour pair is replaced by two, and 16 comparisons have new Holm-adjusted p-values, because the correction now covers 2,628 pairs of runs instead of 2,556. Comparison letters gain the new row's letter where it joins a group; no tie between existing rows changed. The short chart labels now read "Snap Preview" and "Snap 1.1". No other existing number changed.

Results 74c13f91 (1 November 2026)

SubQ Snap's places on the Routing tab move down one (tenth in front of Sonnet 5.5 high, sixteenth in front of Opus 5.5 low, fourteenth in front of Astra low). The paired tests between ranking neighbours pair each new row with the rows on either side of it, in place of two earlier neighbour pairs. 17 other comparisons have new Holm-adjusted p-values, because the correction now covers 2,556 pairs of runs instead of 2,415. Answer key changelog

Every setup is scored on answer key version 2. Question bank SHA-256 797ad6c868bc1c9485bc54203f58839ad995b0443b7149f6a9e36cf0d07df4d7; key fingerprint cd7f998de262e355cd28f596465a51f4158211646ee0cbfbc85f5d8cdeced20a.

Every setup in this benchmark is scored on one frozen answer key. This file lists every change to that key.

How a fix works. A fix to the key needs a check against the book's own key, or a second person who reviews the question and its options without seeing the models' answers. Each fix creates a new key version, adds a row to this file (question ID, old answer, new answer, reason, date) and rescores every run.

To report a wrong key, see CONTRIBUTING.md.

How to identify a version. results.json names the key version under answer_key, with the SHA-256 of the question bank and the key's fingerprint: the SHA-256 of [[id, key, excluded], ...] over every question in answers.json, as compact JSON in question order (answer_key_fingerprint in benchmark_metrics.py).

reproduce.py recomputes the fingerprint and checks every exported answer against the key. export_results.py stops when the answers are graded against a key that is not frozen there.
