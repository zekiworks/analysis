Note
Liquid AI's released d1-2B weights (LiquidAI/d1-2B at 10e7671), a decision model built on LFM3-VL-2B that also reads images. It ran on our hardware through its model card's own call (model.system_one, Liquid's model code in Transformers) behind our HTTP server (servers/d1_server.py), one request at a time. Liquid lists 16 languages for it; Turkish is not among them. Its request times come from one GPU with no other known work while its runs took place, though the GPU was not monitored throughout. Only this model's server showed on it at 11:55 UTC on 1 November 2026, before the runs, and nothing at 12:35 UTC, after them; the one other project with a claim on that GPU confirmed it ran nothing there in between.
