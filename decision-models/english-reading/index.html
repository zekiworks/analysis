English reading

The Text tab's reading questions, asked in English

547 of the Text tab's 656 reading questions, translated into English by a model, asked of the decision models as on the Text tab and compared with the same models' Turkish runs on the same questions. This tab is separate from the leaderboard; it ranks nothing on the Text tab and changes none of its numbers.

Two of the eight models compared scored higher on the English translation than on the Turkish original; six scored lower; two of the eight differences are significant after Holm's correction: Liquid d1-ultra (higher in Turkish) and Microsoft-Decision-1 (higher in English) (Paired test).

About this test

The Text tab's reading questions (units 1 to 6; the grammar questions are left out) were translated into English by Claude Opus 5.5. The same model flagged the questions whose answer depends on Turkish wording; the 109 flagged questions are left out and the other 547 kept. Each decision model answered the kept questions in English and is compared with its own Text tab run on the same 547 questions.

Download: results.json (every number on this page, under english_reading), answers.json (each English run's answers, under english_runs) and english-reading.json (the translator, its prompts, the flags and each question's hash of its English text; no question text).

On 20 questions glide_v2 gave the same answers as Fastino GLiDE v1.2, which runs on our GPU.

Not run

  • Perplexity Decider 27B v1.1: Perplexity's API now answers requests for v1.1 with v1.2, so a new run could not measure v1.1, and no Perplexity API key is available.
  • Celeris-1 Decision: no Celeris API key is available.

Not run by decision

Elephant-1, Mammoth-1, Perplexity Decider 27B v1.2, Perplexity Decider Flash v1.2, Clef, Fastino GLiDE v1.2, vLLM-SR d3, vLLM-SR d3-ultra and Drex Max v1: these models run on our own GPUs, and we decided not to run them in English.

Our method

The translation

The translator is Claude Opus 5.5 (claude-opus-5-5) at effort high; route: Claude Code CLI, Claude subscription, Claude Code version 2.1.312. Its maker has no decision model on our board. It was told to translate faithfully, keep the option letters and their order, not solve the question and not add or remove information (translation prompt version 2976d0f96197).

The flags

In a separate request, the same model was shown each Turkish question, its English translation and the keyed option, and asked whether answering it correctly depends on Turkish wording, with the reasons (flag prompt version 08a5c70222aa). It flagged 109 of the 656 questions; they are left out, and 547 are kept. By reason, as a flagged question can have several:

  • word or phrase meaning: 76
  • idiom: 44
  • sound: 5
  • marked words: 55
  • other: 13

No person checked the translations or the flags. Both prompts in full are in english-reading.json and runner/translate_reading.py.

Asking the decision models

Each model is asked exactly as on the Text tab, with its own settings, one question per request, and with its option probabilities, except for one word of the System One instructions, the options heading and the question itself. The Text tab's instructions:

Which option is the correct answer to this Turkish multiple-choice question?

The English runs' instructions:

Which option is the correct answer to this English multiple-choice question?

The options follow the heading “Options:” instead of “Seçenekler:”, and the question and its options are the English translation. Prompt version 47f5776e71db; every English run used the translations with SHA-256 bf0d47cd385a93050c65906977e199ef7e45d5848dbbdef2bc8d124f4d5abf68. Liquid d1 was asked as d1, while its Turkish runs used d1:free, because Liquid's API no longer serves the d1:free name its Turkish runs used; its model list still names d1, released 29 September 2026.

Runs

One English run per model; five where the model's repeated Turkish runs on the Text tab changed answers. Here: five runs for Liquid d1-ultra, Liquid d1, Jev 1.14.0, Inception Mercury Decide and Microsoft-Decision-1; one for the other three. The English runs are kept out of the leaderboard and its repeats.

The comparison

On the 547 kept questions only: accuracy is the right answers over 547 for the first English run and for the Text tab run (an invalid answer counts as not right), and the difference is English minus Turkish. The paired test is the exact McNemar test on the questions only one of the two runs got right, with p adjusted by Holm's method over the 8 models compared. Where a side has more than one run, its range is the lowest and highest accuracy over its runs, and its answers changed are the kept questions whose answer differs between them.

Why the translations are not published

The site never publishes question text, Turkish or English: the publisher owns the questions. english-reading.json holds instead each reading question's ID, unit, whether it was kept, its flag reasons and the SHA-256 of its English text, with the translator and both prompts, so that a copy of these translations can be checked against it. Translating again with runner/translate_reading.py need not give the same text word for word.
