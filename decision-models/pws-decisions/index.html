PWS-Decisions: the site's models on dated web facts

PWS-Decisions is Parallel Web Systems' benchmark of 100 public English multiple-choice questions whose answers depend on dated facts on the public web. We asked 19 decision model setups and 20 chat model setups that an API still serves, 3 runs each, one question per request. With web search: GPT-6.1 Sol (chat, CLI, with web), Gemini 4 Argon (chat, with web), Claude Fable 5.1 (chat, CLI, with web), GPT-6.1 Terra (chat, CLI, with web), Gemini 3.8 Flash (chat, with web), Grok 4.7 (chat, with web), Claude Opus 5.5 (chat, CLI, with web), Claude Sonnet 5.5 (chat, CLI, with web), Perplexity Decider 27B v1.2 (API, with web) and GPT-6 Luna (chat API) (chat, CLI, with web); every other setup answered without search. This page is not part of the Turkish ranking.

What this measures. Parallel Web Systems made PWS-Decisions. This is an end-to-end comparison of API setups with and without web search on its 100 public questions, which Parallel chose “for their difficulty and alignment with customer outcomes” (its methodology), around its customers' needs for current facts from the web. It is not a general ranking of models: without search, most setups score near random guessing, because the answers depend on dated web facts they were not given.

33 setups have a mean accuracy above the 44.7% chance line (Parallel's random-guess baseline, not a run of ours); every accuracy here is the mean of our 3 runs.

Not run, and why

  • Perplexity Decider 27B v1. Perplexity's API now answers requests for v1 with v1.2. On five of these questions, each of its answers came within 0.007 of one of three v1.2 answers, while v1.2's own three answers differed by up to 0.085.
  • Perplexity Decider 27B v1.1. Perplexity's API now answers requests for v1.1 with v1.2. On five of these questions, each of its answers matched one of three v1.2 answers exactly, while v1.2's own three answers differed by up to 0.085.
  • Fastino GLiDE. Since 10 October Fastino's API answers with its glide_v2 engine, as it did again on 5 November, not the glide engine of the site's run.
  • GPT-6 Luna with web. OpenAI's Decisions API documents no web option: a request takes only model, input, questions, prompt_cache_key, prompt_cache_options and safety_identifier (guide, reference, read 5 November 2026).

Our method

Each question went out as PWS-Decisions' own request (its state, and one choice question with its instructions and its choices), with the setup's model name, to the same API and endpoint as the setup's Text tab run. OpenAI's Decisions API takes the same parts under its own names. One question per request, each provider's requests one after another, the providers at the same time. Timeout 60 s; the runner's retries (up to 5, on 408, 425, 429 and 5xx, and transport failures). Scored with PWS-Decisions' own scorer: a refusal, an error or an invalid answer counts as wrong.

  • Request time: from sending a request to its answer, retries included, over the requests that got an answer; the median and the 95th percentile by nearest rank.
  • The chance line, 44.67%: the mean over the 100 questions of 1 / the number of choices, (77 × 1/2 + 5 × 1/3 + 18 × 1/4) / 100.
  • The 95% interval: 10,000 resamples of the 100 questions with replacement (seed 20261105), each question scored as the mean of its 3 runs' correctness (a missing answer is wrong); the 2.5th and 97.5th percentiles of the resampled accuracy. It is the uncertainty from the question sample; the lowest to highest run is the run-to-run range.
  • Liquid d1 was asked as d1: Liquid's API no longer serves the d1:free name of its Text tab run.
  • Perplexity's own figures: 86% with web on these questions, with 370 ms at the median and 685 ms at the 95th percentile from Perplexity's client (Web grounding for the Decisions API, 4 November 2026); the 51% without is Parallel's leaderboard figure.
  • Parallel's leaderboard (public set, mean of three runs, evaluated 29 October 2026): Parallel Decisions API (fast) 78.33%; Perplexity Decisions (pplx-decider-v1.2, through OpenRouter) 51.00%; OpenAI Decisions API (gpt-6-luna) 42.00%; Baseten Mammoth (baseten-mammoth-27b-latest) 37.00%; TypeSafe Jev 1.14 (jev-1.14.0) 33.33% (the benchmark's repository).
  • The questions and answers are Parallel's: PWS-Decisions version 0.1.0-rc1, gated, for evaluation only. We publish totals only, never a question, an answer or a per-question result.
  • What the runs cost us at list prices: $192.
  • Attempts set aside whole, never merged into a run: GPT-6 Astra, attempt-2: 3 runs, 300 answers, 297 errors, 3 right; GPT-6 Astra, attempt-3: 3 runs, 205 answers, 203 errors, 1 right; GPT-6 Astra, attempt-4: 2 runs, 132 answers, 128 errors, 2 right; GPT-6 Astra with web, attempt-2: 3 runs, 300 answers, 298 errors, 2 right; GPT-6 Astra with web, attempt-3: 3 runs, 210 answers, 208 errors, 2 right; GPT-6 Astra with web, attempt-4: 2 runs, 147 answers, 142 errors, 5 right; GPT-6.1 Sol (API), attempt-1: 3 runs, 300 answers, 238 errors, 46 right; GPT-6.1 Sol (API) with web, attempt-1: 3 runs, 300 answers, 218 errors, 82 right.
