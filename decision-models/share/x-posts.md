```text
We tested a simple rule for trusting a model's answers: accept an answer only when the model reports a confidence of 0.99 or higher, and send every other answer to a stronger model or a person.

Perplexity Decider 27B v1.1 is a decision model: it chooses from given options and returns a probability for each option. On 2,198 non-English exam questions, it passed the rule on 349 (15.9%). None of those 349 answers was wrong. The other 1,849 went to check.

On all 2,198 questions, its accuracy was 66.9%. The rule kept only the answers it was sure of. Zero observed errors does not set an error limit for future decisions: the 95% error estimate range runs up to 1.1%.

In five repeated runs, it chose the same option on every question. Stable is not the same as correct: it repeated the same wrong answer on 728 questions.

Exam questions, not market predictions.

```
