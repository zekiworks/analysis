I don't know option

The Text tab's 2,198 questions, with “Bilmiyorum” as a sixth option

Every question of the Text tab gets one more option after its five answers: F, “Bilmiyorum”, Turkish for “I don't know”. It is always the last option, it is never shuffled and it is never correct. The System One instructions get one added sentence: “If you do not know the answer, choose Bilmiyorum.” Everything else is as on the Text tab: the same 2,198 scored questions and answer key, one question per request, and each model's own settings from its text run.

This tab is separate from the leaderboard. It ranks nothing on the Text tab and changes none of its numbers.

The models: the ten most accurate decision models on the Text tab at results 25290875, plus Base Labs' Elephant-1 and Mammoth-1 and SubQ Snap 1.1 once their text runs are published. Each has one full run; a model whose repeated text runs changed answers gets five.

Download: results.json (every number on this page, under dont_know) and answers.json (each run's answers, under dont_know_runs).

How it was run

The option and the instructions

The added option's exact text is “Bilmiyorum”. It is lettered after the question's own options, and the answer key is unchanged. The full System One instructions:

Which option is the correct answer to this Turkish multiple-choice question? If you do not know the answer, choose Bilmiyorum.

Prompt version 1cdd542b597f (a hash of the prompts with these instructions and this option, computed as for the Text tab's prompt version).

Counts

An answer is right, wrong, “Bilmiyorum” or invalid. An invalid answer counts as neither right, wrong nor “Bilmiyorum”. The mean probability of “Bilmiyorum” is the probability the model gave that option, averaged over its answers that report option probabilities.

Derived non-hallucination rate

For comparison, each model's run with five options (its run on the Text tab, on the same questions) is made to abstain by its own confidence: it answers only where its score reaches a cut-off and abstains on the rest. The cut-off is the one whose attempt rate comes nearest the attempt rate of the run with “Bilmiyorum”; on a tie, the higher cut-off. An answer without a score never counts as an attempt. The derived non-hallucination rate is then the abstentions over the abstentions plus the wrong answers. The table shows the cut-off and the attempt rate it reached.

Repeats

One full run per model. A model whose repeated text runs changed answers gets five runs with the option. Those runs form a repeat set of their own and are never mixed with the Text tab's runs. The table shows the first run; the range covers all of them, and the changed answers are the scored questions whose answer differs between the runs.
