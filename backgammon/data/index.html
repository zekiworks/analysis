Versions

v3
Prompt bg-v2, plays in a seeded random order, invalid answers not retried. Leagues 1 to 3 and the shared positions.
v1
Earlier version Earlier prompt; plays listed in the runner's order. The v1 set of 1,000 positions answered by the v1 setups. Never in a v3 table or chart.
Smoke tests
50 positions outside the shared sets, v3 prompt; only on New models: first look.

How to recompute

  1. Snapshot the league database: python3 tools/site/snapshot.py v3.db STATE (one read transaction; the prompts each model was sent go to STATE/prompts.db).
  2. Score every legal play of every decision with GNUbg 1.08 at 2-ply: tools/site/score.sh STATE/snap.db STATE/plays.
  3. Build and check the site: python3 tools/site/build.py --state STATE --out OUT. The build fails, and nothing is deployed, if a number does not trace to a data file, counts do not add up, leagues or versions mix, a published finding no longer holds, or a file contains a private address or credential.

The scripts are in the jevgammon repository under tools/site/; the fixed thresholds are in thresholds.json.
